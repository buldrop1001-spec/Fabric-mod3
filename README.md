# Input Overlay (Fabric, Minecraft 1.21.4, client-only)

Build: JDK 21, then `gradle wrapper --gradle-version 8.12` once, then `./gradlew build`.
Jar: build/libs/input-overlay-1.0.0-mc1.21.4.jar -> .minecraft/mods/ (with Fabric API 0.119.4+1.21.4).
Right Shift + O opens settings. Config: config/inputoverlay.json
